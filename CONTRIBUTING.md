# Contribution Policy

Triagent is an Apache 2.0 licensed open source project for local-first phishing triage.

Issues, ideas, bug reports, and small focused pull requests are welcome. For larger feature work or architectural changes, please open an issue first so the direction can be discussed before implementation.

Please do not submit private email samples, customer data, credentials, live malware, or proprietary investigation artifacts. Demo data, tests, and examples should use synthetic and safe samples only.

Security issues should be reported privately through the process in [`SECURITY.md`](./SECURITY.md), not through public issues.
