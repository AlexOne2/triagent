# Contribution Policy

Triagent is currently public as a personal portfolio asset and product demo. External code contributions are not being accepted at this stage.

You are welcome to read the code, evaluate the architecture, and use the repository as a reference for what the prototype currently does. Please do not submit pull requests with feature work, broad rewrites, private email samples, customer data, credentials, or live malware.

Security issues should be reported privately through the process in [`SECURITY.md`](./SECURITY.md), not through public issues.
