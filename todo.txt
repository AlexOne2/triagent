## MVP core (thin slice)
- [x] Ingest EML/MSG (manual upload minimum)
  - [x] Manual `.eml` upload implemented (`POST /api/report-eml`, Uploads drag/drop UI).
  - [x] Manual `.msg` upload/parser implemented (`POST /api/report-msg`, Uploads drag/drop UI).
- [x] Parse and normalize
  - [x] Headers/hops parsing (including `Received` hop extraction for IP/rDNS in current parser).
  - [~] SPF/DKIM/DMARC signals shown from `Authentication-Results` header parsing only (no independent cryptographic verification engine yet).
  - [x] URL extraction + normalization implemented.
  - [x] Attachment extraction + hashing implemented for `.msg` ingest (metadata in `attachments`, bytes in MinIO).
- [~] Case lifecycle
  - [x] Case ID available (`reports.id`).
  - [ ] Case fingerprint/dedup workflow not active (legacy clustering removed; fingerprint helper exists but is unused).
  - [~] Verdict workflow exists (resolve/reopen with disposition + classification), but there is no separate "proposed verdict" state requiring formal analyst approval.
  - [x] Analyst notes implemented (`resolution_note` + immutable resolution events).
- [~] Evidence report export
  - [x] Audit export exists (NDJSON + manifests + chain verification).
  - [x] Case-level evidence export implemented (.md + .pdf) including artifacts, rationale, and case audit/resolution history.
- [x] Audit log
  - [x] "Who did what/when/what changed" is implemented for security + mutation events.
  - [x] Tamper-evident append-only hash chain + verify/export/prune controls implemented.
